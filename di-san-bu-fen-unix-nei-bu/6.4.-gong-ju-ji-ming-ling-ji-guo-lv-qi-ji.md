# 6.4 工具即命令即过滤器即……

UNIX 有数以百计的程序可以作为 shell 命令执行。人们有时把它们称作工具，以强调它们能拼起来搭建更大的东西。许多工具是很小的程序，专门用来干一件简单的事——正因为如此，工具才这么多。

造工具的思路极其强大，对新手却可能令人不知所措。有些人就喜欢找一个能精确完成自己想要之事的程序，把两样东西组合起来的念头简直让他害怕；在你完全不知道系统提供了什么的时候，找合适的工具来搭东西，当然会很沮丧。

想要对 UNIX 有几分自在的感觉，你就该花时间熟悉其中相当一部分工具。翻翻命令的手册页吧——你可能觉得这无助于解决手头的问题，其实有用，你会认识所有工具。光会组合工具还不够，你必须知道有哪些工具可供组合。

UNIX 不是那种你每个月坐下来一次就能立刻上手的东西。想象你现在下到地下室，想做个大件，比如一张沙发。你要做的东西很好理解，但在学会量尺寸、锯木头、敲钉子、绷面子和贴创可贴这些基本功之前，你一定会碰壁。

本节余下部分简要介绍最常用的 UNIX 命令。它们全是用户级命令——直接敲给 shell。我们还附上了命令名的词源，因为有些名字颇为费解。大多数命令都有可选的选项或参数，但我们只提每种命令最常见的用法；完整说明请查阅你系统上的手册页。

命令还有几百条，但这里列出的，大概是你 90% 的时间里会用到的。我们并不是要无视那些偶尔才用上一次的几百条命令——在掌握基础之前，它们不重要。

这里会提到几条与编程有关的命令，但整个话题在程序员一章里有详尽得多的讨论。管理员一章则讨论一些与维护 UNIX 系统相关的命令。

## 6.4.1 文件操作命令

这些是基本的文件操作命令，包括复制、删除、列出文件等。记住：既然目录和设备也是文件，大多数命令对它们同样适用。

**cd** 切换当前目录。是“change directory”的缩写。

切换之后，所有文件名都相对于当前目录，包括下一条 cd 里的文件名。与 pwd 对照。

**cp** 复制文件。是“copy”的缩写。

cp 保留原文件，用新名字做一个副本。cp 也能复制目录树。uucp（UNIX-to-UNIX cp）是 cp 的亲戚，可以在计算机之间复制文件。cp 家族还有其他变体。与 mv 对照。

**df** 显示文件系统中的空闲空间。是“disk free”的缩写。

df 其实报告全部空间、已用空间以及空闲空间。df 的工作方式是记录所有空闲空间，而不是去查看文件。与 du 对照。

**du** 显示目录中已用的空间。是“disk usage”的缩写。

du 统计一个目录下所有文件占用的空间；如果其中有文件是目录，du 会递归统计。与 df 对照。

**find** 对目录中任意文件执行操作。是“find”的缩写。

find 查找符合给定描述的文件；找到之后，可以对文件执行指定的 shell 命令（比如打印它的名字）。find 这东西，直到你真的需要它，才体会得到它的好。（手册页非常难读，但值得费这个劲。）

**ls** 列出目录中的文件。是“list”的缩写。

我们也不知道它为什么叫这么个怪名字，但它够短，你很快就能习惯。

> **这些命令名都是哪儿来的？**
>
> 你可能觉得 ls 这名字挺怪，但还有更离谱的。伯克利引入的 biff 命令用来打开异步邮件通知，这样你一收到邮件，终端上立刻就会收到提示。传说写 biff 的程序员想不出一个简短的名字，就用了常在他工作的伯克利走廊里晃荡的一条狗的名字。为什么？因为邮差一来，那条狗就叫！

**mkdir** 新建目录。是“make directory”的缩写。

需要这条特殊命令，是为了确保所有目录都带有 . 和 .. 这两个条目。

**mv** 移动文件。是“move”的缩写。

把文件移到文件系统中的新位置。大多数别的操作系统把这类操作叫“重命名”，但在 UNIX 文件系统里，名字既决定文件叫什么，也决定文件出现在哪里。与 cp 对照。

**pwd** 打印当前目录。是“print working directory”的缩写。

与 cd 对照。

**rm** 删除文件。是“remove”的缩写。

由于一个文件可以有不止一个名字，rm 通常只是删掉那个文件名。如果这是文件的最后一个名字，文件本身也会被删掉。一个文件若只剩这一个名字，被 rm 之后就没办法“取消删除”了。

**which** 这条命令会执行哪个程序？是“which”的缩写。

打印出给定命令将要执行的程序。当你的搜索路径里有一大堆目录时，命令究竟来自哪个目录未必一眼看得出来。（仅 BSD 有。）

## 6.4.2 数据处理命令

这些命令对文件内部的数据执行操作。不过，其中大多数命令既能处理文件，也能处理输入输出流。**过滤器** 是接收输入（通常来自 stdin）、并据此产生输出（通常送到 stdout）的程序。这里的大多数程序都称得上过滤器。

**cat** 把输入复制到输出。是“concatenate”的缩写。

这是所有过滤器的原型：除了把 stdin 复制到 stdout，它什么也不干。如果给 cat 一个文件名，它就把文件复制到 stdout——这也是它的主要用途：在终端上列出文件内容。

**diff** 显示两个文件的差异。是“difference”的缩写。

diff 也能作用于目录。

**echo** 回显参数。是“echo”的缩写。

echo 主要用于 shell 脚本内部，产生各种说明性文字。交互式地把它当命令敲，用来显示 shell 变量，其实也很有用。

**ed** 编辑文件。是“editor”的缩写。

一个简单的行编辑器。不妨试试屏幕编辑器。与 sed、grep 和 vi 对照。

**file** 显示文件类型。是“file”的缩写。

file 通过查看文件开头几个字节，猜测你给的文件是什么类型。它可能被蒙骗，但不太容易。与 od、strings 对照。

**grep** 搜索模式。源自 ed 命令“global regular expression print”（全局正则表达式打印）。

grep 在输入中搜索由正则表达式定义的模式，凡是匹配的行都打印出来。与 ed、sed 对照。

**head** 打印开头几行。是“head”的缩写。

head 适合快速瞄一眼文件内容。与 cat、file、tail 对照。

**more** 一次一屏地显示数据。是“more”的缩写。

more 像 cat 一样把输入复制到输出，但每显示一屏就暂停。有些系统上它叫 page。与 cat 对照。

**od** 打印未经解释的数据。是“octal dump”的缩写。

把输入按字节或字拆开，用十六进制、八进制或字符形式打印。od 不对输入作任何解释，所以你能真真切切看到数据里是什么。与 cat 对照。

**sed** 非交互式编辑器。是“stream editor”的缩写。

和 ed 一样，只不过它处理的是流而不是文件。当需要像手工一样编辑文件时，shell 脚本里常调用 sed。与 ed 对照。

**sort** 排序数据。是“sort”的缩写。

**strings** 显示可打印字符串。是“strings”的缩写。

strings 适合在不运行程序的情况下琢磨它是干什么的：你看到程序里的错误信息和其他可打印字符串，然后靠猜。就当是个游戏来玩。与 file 对照。

**tail** 打印最后几行。是“tail”的缩写。

tail 适合看日志或诊断文件——你只关心最新的数据（在文件末尾）。与 head 对照。

**vi** 屏幕编辑器。是“visual”的缩写。

编辑器 ed 的大幅增强的屏幕版。与 ed 对照。

## 6.4.3 编程命令

这些命令通常以程序为输入，有时输出还是另一个程序。某种意义上，本章讨论的任何命令都可以视为可编程的，只是有些比另一些更复杂。

**adb** 程序调试器。是“assembler debugger”的缩写。

adb 用来调试汇编程序，或者你手上没有源码的 C 程序。这很痛苦。

**a.out** 用户程序。是“assembler output”的缩写。

C 编译器默认以这个名字产生用户程序。

**awk** 模式处理语言 awk。得名于三位作者“Aho, Weinberger and Kernighan”。

一种解释型编程语言，偏重 Snobol 式的字符串处理。当你的问题用 shell 太难解决、又不值得写一个 C 程序时，就找 awk。

**cc** C 语言编译器。是“C compiler”的缩写。

把 C 源文件翻译成机器可执行程序。cc 其实只是一大堆程序的前端，其中包括 cpp（C 预处理器）和 ld（链接器）。

**make** 从源码构建程序。是“make”的缩写。

make 从源码生成可执行程序。它用一个程序来控制编译、lex、yacc 等等这一大摊复杂活儿。

**sdb** C 程序调试器。是“symbolic debugger”的缩写。

sdb 让你诊断、试验正在运行的 C 程序，或对死掉的程序做事后分析。dbx 是另一个 C 调试器，比 sdb 好，但并非所有系统都有。

**sh** Bourne shell。是“shell”的缩写。

大多数 shell 脚本都是为 Bourne shell 写的。如果脚本没有被标为可执行，可以用这条命令手动运行。

## 6.4.4 杂项命令

**date** 显示时间和日期。是“date”的缩写。

**kill** 向进程发送信号。是“kill”的缩写。

kill 的主要用途是向进程发送终止信号，把进程杀掉；其实它可以发送任何信号。

**mail** 收发电子邮件。是“mail”的缩写。

**man** 显示在线文档。是“manual”的缩写。

man 显示“程序员手册”中的页面（尽管这本手册也包含这里讨论的所有工具和命令）。给它一个关键词，`man -k` 会打印标题中含该关键词的手册页名称。有些系统把它做成了单独的程序，叫 apropos。

**ps** 显示进程信息。是“process status”的缩写。

显示系统上任意或全部进程的信息。

**who** 显示已登录用户。是“who”的缩写。
