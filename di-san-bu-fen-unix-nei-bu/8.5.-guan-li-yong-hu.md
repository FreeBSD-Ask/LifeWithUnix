# 8.5 管理用户

长期以来，UNIX 在用户管理上都走钢丝：既要别挡用户的路，又要提供足够的控制、让系统好用。早期 UNIX 只生成少数几个文件（在 **/usr/adm** 里），记录连接时间和正在执行的进程。

新版本的 UNIX 开始拥有越来越多的用户管理和跟踪工具。System V 和伯克利 UNIX 都有全面的使用情况跟踪系统，可以按用户时间与内核时间、I/O 操作等分类统计。说实话，有点吓人。

## 8.5.1 用户账户

真正必不可少的管理工具之一，是 **/etc/passwd** 文件。这个文件为每个获准使用系统的用户保存一行——真够简洁的！

**/etc/passwd** 是文本文件，可以用任何编辑器编辑，格式确实很简单。不过，如果存在多人同时更新它的风险，就该用某种锁定机制。vipw 正是为此设计的：它在口令文件上启动 vi，并在你完成之前阻止别人编辑。

**/etc/passwd** 里的一行可能长这样：

```
dmr:tFLKiPzkWavm:29:5:Dennis Ritchie:/usr/dmr:/bin/ksh
```

每行七个字段，用冒号分隔：

1. 登录名。
2. 加密后的用户口令。
3. 用户 ID 号（叫“uid”），系统内部用它区分用户。
4. 组 ID 号（见下一节）。
5. GCOS 字段。通常是用户全名，也可以放电话号码或无聊的注释——也就是说，它没有定义。历史上叫 GCOS 字段，是因为当初用来指定一个记账 ID，随远程批处理作业提交给贝尔实验室的 GCOS 系统。
6. 主目录。
7. shell。也用于创建开箱即用系统和登录命令。

这套简单的方案足以提供非常灵活的用户环境。往系统里加用户只是小事：加一行描述，再给他建个主目录。（实践上，给他几个模板文件，如 .cshrc 和 .login 或 .profile，也有帮助，但并非绝对必要。）

shell 字段特别有用。允许用户运行不同的 shell，就能把系统调到适合任何用户水平的程度：非技术用户可以用简单的 shell，比如面向菜单的程序；受限用户可以用受限 shell，比如只能访问游戏。还可以把命令安装成用户：比如创建一个登录 shell 为 **/bin/who** 的用户 who，那么以 who 登录就能运行 who 命令（命令结束后，你也就登出了）。

这个文件只有超级用户可以写。通过限制文件中的信息量，也就限制了用户不能改动的信息量。用户可能想改的字段（如口令字段）由一个专门程序修改，它只开放正确的那一个字段。

与大多数其他操作系统不同，**/etc/passwd** 人人可读。这可行，是因为口令以加密形式存储——对任何人（除了系统本身）都毫无用处。有意思的是，最初的实现使用了一种特别强壮的加密算法，基于二战中德国使用的 Enigma 密码机。理论上可以破解口令，但代价高得离谱。（再说，猜口令还容易些。）

## 8.5.2 组账户

**/etc/passwd** 的第四个字段定义一个组 ID（或“gid”）。系统内部用这个数字把一组用户与共同的访问权限关联起来。组里的每个用户于是能访问任何按组权限允许访问的文件。

有一个叫 **/etc/group** 的文件，看起来与 **/etc/passwd** 很像。它按组名、口令、数字组 ID 和组成员列出各组。口令是可选的，它让本来没有权限使用该组的人也能使用。下面是 **/etc/group** 的一个典型条目：

```
admin:q3gn89:16:carol,henry,joe,tony,gail
```

和口令文件机制一样，组文件机制也简单易用、灵活。

## 8.5.3 通信

既然 UNIX 用户和管理员是同一拨人，用户与管理员之间的沟通就很顺畅。通过计算机提供沟通的工具包括：

* mail——给用户发邮件。
* write——往另一个用户的终端写消息。
* wall——往所有活动终端写消息。适合警告即将停机。

特别重要的工具是某种新闻公告板系统。UNIX 自带一个相当简陋的，公有领域里有许多更好的，你应该马上弄一个。我们强烈推荐能支持 Usenet 的系统之一（见地下世界一章）。即便只在单个系统上的用户之间通信，这些系统也很好用。

## 8.5.4 uucp

uucp 代表“UNIX-to-UNIX cp”。和 cp 一样，uucp 复制文件，只不过它能把文件从一台 UNIX 机器复制到另一台。uucp 的语法与 cp 非常相似，唯一区别是文件名可以带主机前缀，两者之间用叹号分隔。比如，下面这条命令把 **/etc/passwd** 从一台机器（lurch）复制到另一台（kanamit）：

```sh
uucp lurch!/etc/passwd kanamit!/etc/passwd
```

uucp 最初设计为在 RS-232 串行线上运行（任意速率），后来经过增强，支持许多不同类型的通信介质。

uucp 有检错和纠错协议，确保文件正确传输。由于不需要特殊硬件，你可以用 uucp 把计算机连成存储转发网络，除了连线几乎不花什么钱。uucp 还能使用拨出和拨入调制解调器。Usenet 的很大一部分（见地下世界一章）就靠拨号 uucp 连接运转。

uux 是 uucp 的表亲，允许远程执行命令。语法与 uucp 相同，只是可以指定任意命令（同样以叹号开头）。文件被送到远程系统后，命令在那里执行。

如今虽有快得多的网络，uucp 网络在 UNIX 系统上仍相当普遍。部分原因是：uucp 是每套 UNIX 系统都自带的唯一一种机器间通信系统。与现代网络相比，uucp 网络很慢，但在许多年里，它都是一种特别便宜、有效的网际互联方式。
