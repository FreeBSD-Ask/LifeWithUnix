# 6.1 海边拾贝：挑选 shell

被问到“UNIX 是什么”时，许多人脑子里想到的就是 shell（得名于它是系统最外面的一层）以及它控制进程和文件的那些典型特性。

当你敲下 cat、ls 这类命令时，侧耳倾听的程序就是 shell。shell 是最常用来启动和控制其他程序的程序，编辑器、编译器、游戏等等都算在内。shell 不是某个特定的程序——实际上可以是任何程序；用户能自己写一个 shell。这样，UNIX 的用户界面就能按每个用户的口味彻底改头换面。

允许用户拿任意程序替换默认用户界面，是 UNIX 的一大发明。即便在今天，大多数操作系统也不让用户替换用户界面；就算允许，那个程序也得遵循一套特殊的约定。

某种程度上，对 UNIX 命令晦涩难懂的抱怨可以用一句“那你自己写个 shell 啊”来回应。话虽说得轻巧，写好一个 shell 却需要相当的专业功底。不过我们认为，UNIX 的设计者清楚：设计一个让所有人都满意的界面太难了。于是他们留给我们一个让程序员自己满意的界面，同时留下了一个面向未来的钩子。

许多人接过了这个钩子，于是今天我们能看到带菜单界面、AI 界面、图标界面的 UNIX 系统。关键在于：这一切都做得到。

一个写得好的 shell 用起来是种享受。写好它当然需要功力，尽管基本思路简单得很：

```c
while (1) { prompt("command:"); read(command); execute(command); }
```

真正的 shell 比这复杂不少，得处理信号、中断、管道和 I/O 重定向。shell 的一个重要特点是：和任何 UNIX 程序一样，它的 I/O 可以被重定向。所以，如果你把它的输入从键盘改道到文件，它就会执行一组 shell 命令——这就叫 shell 脚本。

shell 脚本可以简单到只是一组待执行的命令。即便这么简单的概念，也足以把现成的程序串成新的、更强大的程序，而 shell 正是干这个的理想工具。又因为各种 shell 都实现了编程语言结构，shell 脚本往往看起来很像程序，能做相当精巧的事，而不只是简单地执行一串命令。和编程语言一样，shell 的选择也可以因应用而异。

我们看到不同的人用不同的 shell，许多人还不止用一种。这对新手来说有点晕，但熟悉不止一种 shell 是有重要理由的。

**sh**，又称“Bourne shell”（得名于贝尔实验室的 Steven Bourne），是最简单的 shell。它堪称 shell 的最小公分母：具备编程语言的雏形（类似 Algol-68）、简单的变量，如此而已。它流行是因为它比其他 shell 出现得早，而且它是唯一保证在每套 UNIX 系统上都能找到的 shell。也正因如此，人们常常用别的 shell 交互式工作，却为 sh 写脚本。

**csh**，又称“C shell”，由伯克利和 IIASA 的几个人写成。sh 的编程语言结构像 Algol，csh 的则像 C 语言，“C shell”之名由此而来。讽刺的是，大多数人觉得 csh 更难编程，于是继续为 sh 写脚本，只是交互时用 csh。

csh 真正值得注意的特性是作业控制、历史和别名——尽管名字暗示的是别的。作业控制让你用单次按键在前台和后台之间调动多个进程；历史记录保存之前执行过的命令，其依据是你很可能重复执行某些命令或它们的变体。与 sh 相比，csh 能大幅减少完成同样工作所需的击键数。别名是给命令行起的名字，csh 替你记着。

csh 随所有基于伯克利的 UNIX 分发，通常也包含在号称“带伯克利增强”的 AT&T UNIX 里。

**tcsh** 是 csh 的一个流行变种，属于公有领域。它包含 csh 的全部特性，另加类似 BBN 的 Tenex 系统的“命令补全”：你可以只敲命令和文件名的开头，只要足以消歧，系统就能自动补全。tcsh 还提供 Emacs 风格的命令行编辑。

**ksh**，又称“Korn shell”（得名于贝尔实验室的 David Korn），是常用 shell 中最强大的一个。它与 sh 向上兼容，包含 csh 和 tcsh 的许多优点，还提供 vi 或 Emacs 风格（随你挑）的命令行编辑。它也比其他任何 shell 高效得多。ksh 可从 AT&T Toolchest（见讲应用的章节）作为非捆绑产品获得。

我们预计 ksh 最终会作为默认 shell 随 UNIX 分发。我们鼓励大家弄一份 ksh，把它当作“标准 shell”。ksh 的说明见 David Korn 与 Morris Bolsky 合著的《The Korn Shell Command and Programming Language》（Prentice-Hall）。

这里讨论的是最常见的几种 shell，你在自己的 UNIX 系统上遇到它们的概率比别的 shell 大。不过，市面上还有许多别的 shell，不少第三方公司也开始提供 shell，有时还针对特定系统做了优化。其他值得一提的有：vsh（Microsoft 的可视 shell）、deskmate 和 tsh（Tandy）、MultiView（SCO）、sysadmsh（SCO 的系统管理员 shell）、dsh（American Management Systems 公司的目录 shell），以及 ATvanced Office System（Technology Research Group 公司）。

注意，描述 shell 可能和描述 UNIX 一样难：它们同样容易被改，而且随着作者添加新特性，它们总在变。比如 csh 每一次新发布都添了特性；sh 在演化过程中也从别的 shell（包括 csh）借来了许多想法。csh 和 ksh 还在继续增强，我们提到的许多其他 shell 也一样。所以，如果哪天你发现某个你以为是某 shell 独有的特性，早晚出现在所有 shell 里，别大惊小怪。
