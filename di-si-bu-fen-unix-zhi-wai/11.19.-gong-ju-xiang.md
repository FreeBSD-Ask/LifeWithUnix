# 11.19 工具箱

AT&T 的 UNIX System Toolchest 虽不是应用，放在这里讲倒也合适。Toolchest 是一家自动化的软件商店。

用 Toolchest，你可以在电子化的软件仓库里浏览，挑好想要的，然后下单。软件以电子方式送到你的计算机上。

它在现实中运作起来简单得令人意外：你从一台智能终端拨号连上 Toolchest，第一次可以以 guest 身份登录，并开一个用于计费的合同；接着就能在大量软件中浏览。比如，你可以这样拿到 awk、HoneyDanBer uucp 和 Korn shell 的最新版本；若干公有领域程序则免费提供。最后，软件当晚通过 uucp 送达。

Toolchest 最初是为解决 AT&T 内部的分发问题而设的：内部有数千套 UNIX 系统，数百名程序员不断修改 UNIX 程序，怎么可能让所有机器都跟上最新程序？答案是：别想着让所有机器都保持最新，让用户按需索取最新副本。这很合理——大多数人并不需要每个程序的最新副本，但一旦在某个程序里撞上 bug，就希望它马上修好。

许多其他公司也开始支持自家的拨号工具箱，但 AT&T 的最负盛名，UNIX 期刊上已有多篇关于它的技术论文。更全面的介绍见 Catherine Brooks 的《Experiences with Electronic Software Distribution》（1985 年夏季 USENIX 会议录）。Toolchest 的电话号码：美国 201-522-6900，伦敦 44-1567-7711，东京 81-3-431-3670。
