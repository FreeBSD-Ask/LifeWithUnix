# 11.10 第四代语言

> “我的语言的界限，意味着我的世界的界限。”——Ludwig Wittgenstein

第四代语言（4GL）是高级语言（3GL）之上的高层接口。理论上，程序员把问题规格作为 4GL 的输入，系统自动把规格转换成代码。

现实中，大多数 4GL 仍是过程式的。4GL 其实只是成了一个流行词，指那些允许你用类英语句子编程、并在数据库操作、屏幕格式化和用户界面方面配有一整套库的语言。

4GL 不会让程序员失业，却能极大地加速某类编程任务，尤其擅长做原型。我们这么说，是因为它们也可能很慢——这有点像用 shell 脚本写应用。

一些 4GL 有 ABF（Relational Technology）、Accell（Unify 公司）、DataFlex（Data Access 公司）、Empress/32、Informix-4GL（Informix Software 公司）、M-Builder（Rhodnius 公司）、Oracle（Oracle Systems 公司）、Progress（Data Language 公司）、Today（bbj Computers International）和 System Z（Zortec 公司）。
