# 11.16 shell 编译器

UNIX shell 是解释器，这意味着它要花大量时间解释 shell 脚本里的指令，然后才执行。编译器与解释器不同：程序只看一遍，却能执行许多次，因此生成的程序快得多。

人们最初把 shell 脚本设想成原型工具，效率无关紧要。可 shell 编程实在太容易（而 C 编程太难），许多有价值的 shell 程序从未改写成编译后的程序。

有几家公司推出了 shell 编译器：它们以 shell 脚本为输入，产出可执行程序。视原脚本而定，可能获得惊人的加速——把 shell 程序的运行时间减少 90% 相当可信。

三个 shell 编译器是 CCsh（Comeau Computing）、QuickShell（UniPress Software）和 Shacc（Concentric Associates 公司）。它们都只编译 Bourne shell 脚本。
