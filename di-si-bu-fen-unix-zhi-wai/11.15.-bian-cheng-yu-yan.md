# 11.15 编程语言

> “想要 PL/I？你知道上哪儿找。”——Dennis Ritchie

UNIX 自带的语言已经不少，但仍有诸多理由向第三方厂商购买。一来，每天都有新语言（以及标准委员会带来的新版本）诞生；二来，要支持新机器，可能需要交叉编译器；三来，有些厂商造语言的本事比你的原硬件厂商强。既然 UNIX 现在可以“拆分”或零买，挑一门语言就跟给音响系统挑一个组件差不多。

* **APL**：Dyadic Systems 公司、I. P. Sharp Associates、俄勒冈州立大学、STSC 公司。
* **Basic**：ABC Development Systems 公司、AT&T、Basis 公司、Basmark 公司、Concept Omega 公司、Control-C Software、Cromemco 公司、Databoard 公司、HCR 公司、微软公司、Microware Systems 公司、NKR Research、Philon 公司、Silicon Valley Software、Software Innovations 公司、Tektronix 公司、UX Software 公司、UniPress Software 公司。
* **C**：Alcyon 公司、AT&T、Flexible Computer 公司、自由软件基金会、Interactive Systems 公司、MetaWare 公司、微软、Microware Systems 公司、Microtec Research、Oasys、Oregon Software、Silicon Valley Software 公司、Software Development Systems、Southwest Technical Products 公司、Systems & Software 公司、UniPress Software 公司、Whitesmiths 公司。

几乎每套 UNIX 系统都带有厂商提供的 C 编译器，但购买第三方版本仍有正当理由。典型理由是交叉编译——需要为另一台机器生成代码，而默认的 C 编译器很少提供这种能力。

另一个理由是，有些公司专做高性能编译器。这类产品固然诱人，但大多数客户还是更愿意用随系统而来的 C 编译器。我们看到的情形，往往不是最终用户去买第三方 C 编译器，而是 UNIX 系统厂商自己投资第三方编译器产品，并把它嵌入自家最终产品。
