# 11.9 编辑器

> “vi 是一坨袋熊屎”——1985 年欧洲 UNIX 用户组辩论会题目

UNIX 最初自带行编辑器 ed。UNIX 一“走向公众”，它的第一个商业被许可方就写了一个屏幕编辑器（Rand 编辑器）。BSD 发行版包含 vi 屏幕编辑器，它沿用 ed 的大部分命令，因而受到那些不愿让学 ed 的功夫白费的人欢迎。vi 已被纳入大多数 UNIX 发行版。（讽刺的是，vi 的作者 Bill Joy 多次说过，早知道 vi 会这么流行，他根本不会写它。）

最流行的屏幕编辑器是 emacs，最初由 Richard Stallman 用 teco 为非 UNIX 机器编写，后来由 CMU 的 James Gosling 用 C 重新实现。事实上，emacs 在登上 UNIX 之前就已经相当流行了。如今 emacs 依然极受欢迎，部分原因是它几乎为现存每一种计算机和操作系统都实现过，而且许多实现属于公有领域。

尽管 vi 和 emacs 都有公有领域版本，如今仍有许多公司支持两者的商业发行版。你究竟要公有领域版还是商业产品，得自己拿主意——不过我们对 GNU 的公有领域 emacs 评价很高。销售编辑器的公司还有 CCA（Emacs）、Custom Software Systems（PC/VI）、Enterprising Ideas 公司（ae）、Lugaru Software 公司（Epsilon）、Fenix Software（Fenix）、Grand Software 公司（Grand Editor）、Marc Software（WordMarc）和 UniPress Software（vi-PLUS、emacs、cmacs）。

这些编辑器中有许多远不止于字符操作：大多能检查拼写，不少还带同义词库。令人惊讶的是，很少有产品比得上名为 Writer’s Workbench 的工具（至今仍由 AT&T 销售）。这类程序帮助写作者检查语法问题，从拼写错误到更复杂的结构问题，如标点、分裂不定式、连写句和性别歧视用语。它们依据内置规则提出修改建议，作为写作的辅助。
