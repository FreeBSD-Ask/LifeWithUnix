# 11.11 图形

UNIX 有几个初级工具，用来画线、圆和样条曲线。这套系统（叫 “plot”）通过若干可用管道连接的过滤器实现，手法非常巧妙。虽然我们推荐不出具体的替代品，但建议你无视这套软件——它相当不灵活、不友好，在第三方图形软件面前黯然失色。

需要图形功能的应用里，有许多出色的终端用户产品可用于绘制图形。简单用途包括商业和科学演示用的展示图形（如柱状图、饼图）。销售展示图形工具的公司有 AT&T Information Systems、Precision Visuals 公司、Data Business Vision 公司、Graphic Software Systems、Arens Applied Electromagnetics 和 Quality Software Products 公司。其中最著名的大概是 AT&T 的 DWB（Documenter’s Workbench），它包含 grap（图形）、pic（图片）以及其他程序，让你能非常容易地在 troff 里做图形。

更高级的需求出现在 VLSI 设计、图像处理这类应用里。图形学是个相当成熟的领域，大多数系统至少带有 Core、GKS 或 PHIGS 图形库之一的实现；这些库也可从第三方供应商处获得，如 Advanced Technology Center、ISSCO、Omnicomp Graphics 公司、Peregrine Computer Systems、Precision Visuals 公司和 Template Graphics Software 公司，它们的产品能轻松支持各种复杂的高级应用。

更复杂、更苛刻的图形工作也能在 UNIX 上完成，尽管通常是一次性的。这种最前沿的工作之所以在 UNIX 系统上更可行，原因不难理解：每年都有新的显示系统诞生，而 UNIX 总是第一个把软件移植上去的；另一个原因是效率往往是许多图形应用的重要考量，用 C 写是条好路（很大程度上，C 正在取代 Fortran 成为图形工作的首选载体）。

**图形趋势**

伯克利和贝尔实验室的研究，既体现了 UNIX 编程哲学，也体现了它与图形学的关系。伯克利的 Carlo Sequin 设计了一套叫 UNIGRAFIX 的工具，能创建 3D 和 4D 对象，并通过管道和过滤器操控它们的几何形状。（见《The Berkeley UNIGRAFIX Tools》，技术报告 UCB/CSD 86/278。）贝尔实验室的 Tom Duff 也以类似风格写了一系列程序，它们围绕一个公共数据结构协同工作，产出高质量计算机图形。（见 1985 年 SigGraph 会议录中的《Compositing 3-D Rendered Images》。）同样来自贝尔实验室的 Potmesil 和 Hoffert 则运用其中的一些想法创造了 FRAMES。（见 1987 年 SigGraph 会议录中的《Frames: Software Tools for Modeling, Rendering and Animation of 3D Scenes》。）

这件事的意义相当优雅：与其做一个能为所有人做所有事（方式还复杂得让人糊涂）的单一巨型程序，不如按需把若干小工具组合起来。比如，一个工具生成 3D 对象，下一个给它们着色，另一个加上合成相机视角，诸如此类。要换用不同的着色或光线追踪算法，简单到只需敲一行 UNIX 命令。
