# 9.2 公有领域软件及其他免费软件

相当多的 UNIX 软件属于公有领域。为什么？UNIX 早年根本没有能赚钱的分发渠道，只有非营利的。即便今天，许多人对软件生意或赚钱也毫无兴趣；许多程序甚至不适合市场，卖的钱还不够付经营企业的日常开销。

免费软件的另一个来源是学生，他们很少指望报酬。大学里写的某些软件能否商业化，取决于经费来源；但它可以免费送人。一些大学的编程项目后来成了极其流行的计算标准（比如 emacs）。许多大学还提供 UNIX 软件的分发集。

如今 UNIX 软件已有许多能赚钱的分发渠道，但当初催生公有领域 UNIX 软件的许多理由依然存在。何况，写 UNIX 软件的人比以往任何时候都多，而为其他计算机系统写的软件，也比以往更容易移植到 UNIX。

当然，这里有个取舍。比如，公有领域软件通常很难获得像样的支持，一般是“按现状”提供。好的一面是，你拿到的一定是源码形式，可以自己清掉残留的 bug，加入你感兴趣的功能。如果你是个水平尚可的程序员，能拿到全部源码并自行维护，放弃厂商支持的产品也许是划算的。

请注意：大多数免费软件属于公有领域，但并非全都如此。特别是有些软件受版权保护（如 MINIX、Mach），未经作者事先许可，你不能将其商业化销售。版权允许你制作“合理”数量的副本。理想情况下，结果对你有利。比如 Mach 的作者希望大家把修改和 bug 修复寄回，好让他们统一协调所有改动、重新分发单一版本。（Mach 在讲未来的章节里讨论，MINIX 在本章后文讨论。）

## 9.2.1 存档站

许多站点维护着庞大的公有领域软件存档。有些放在线上，可通过 uucp 或 ftp 直接取用；有些太大，无法常年在线，只能向特定的存档管理员索取。别提出“请把所有 1985 年 3 月的源码都寄给我”这种请求。存档访问是志愿性质的；如果你要离线源码，就得自备磁带并付回邮费。

由于存档通常没有本地管理员和预算的支持，我们无法在此一一记录；同样，它们有时会在几乎毫无通知的情况下关停。了解哪些站点有最新存档、存了些什么，最好的地方是 Usenet 新闻组 comp.sources.d 和 net.sources。

## 9.2.2 Usenet 源码新闻组

源码的一个常见来源是 Usenet 的源码新闻组。这类新闻组用来张贴各种源码：比如 comp.sources.games 放游戏，comp.sources.amiga 专对 Amiga 微机，comp.sources.bugs 则登载源码新闻组里已张贴源码的 bug 报告与修复。

还有许多面向其他操作系统的源码新闻组，质量之高非同寻常（若不如此，作者会被 bug 报告淹没）。这里常能见到本来无从获得的软件：许多论文项目、实用程序或教学代码片段都会出现在这些组里。对于这类资源，Usenet 是无价之宝。

## 9.2.3 用户组软件

大多数用户组都以象征性的分发费用提供用户投稿的软件。比如 /usr/group 和 USENIX 都定期向会员分发软件。由于软件量很大，你得具体申请某种软件，而不是因为入了会就自动收到。它们备有适合不同系统的多种发行版；某些软件可能需要你出示 UNIX 许可。

许多厂商也有用户组，只为自家计算机和用户提供软件（也就是说，不通用）。事实上，计算机会议上经常演示的许多程序并非厂商所写，而是用户写的。详情请联系你的计算机制造商。

PC/MS-DOS 世界还产出了大量 C 软件。它们虽非专为 UNIX 而写，但其中许多几乎不用改动（甚至完全不用改）就能在任何 UNIX 机器上运行。跟踪这类软件最好的地方之一是 C 杂志，比如《C Users Journal》。

## 9.2.4 GNU 与自由软件基金会

为了回应 AT&T 和许多其他计算机公司强推的严格 UNIX 软件许可，自由软件基金会（FSF）成立了，它“致力于消除对软件复制、再分发、理解和修改的限制”。

FSF 最初由 Richard Stallman（emacs 第一版的作者）创建，着手重建 UNIX 最精华的部分，所有这些只需支付复制软件的成本。这些软件不属于公有领域，但可以自由复制、修改和赠送。FSF 的这套软件被戏称为 GNU，即“GNU is Not UNIX”（GNU 不是 UNIX），读作“gä-new′”。

大量 UNIX 软件被重写并贡献给了 GNU 系统。要注意，这些软件没有一件使用受版权保护的 UNIX 软件。GNU 期望在不久的将来提供 UNIX 的大部分工具和内核（可能基于 CMU 的 Mach）。GNU 还维护一份名单，列出可以为 GNU 软件提供支持（包括 bug 报告、移植等）的联系人。

到 1987 年 6 月，GNU 已包括 GNU Emacs（极其精巧的通用可扩展编辑器）、GDB（源码级 C 调试器）、GCC（C 编译器）、BISON（又一个 yacc）、X Windows（可移植、网络透明的窗口系统）、MIT Scheme（词法作用域的 Lisp 方言）、GNU Chess（C 级棋手，可让多台机器并行计算以提高棋力）以及 Hack（类似 Rogue 的冒险游戏）。所有软件都以源码形式分发！

获得 GNU 软件最省事的办法，是找已经有的人复制一份——不用付钱，也不用签许可协议！GNU 软件也在各存档站提供。最新的在线存档经由 Arpanet 主机 prep.ai.mit.edu；更多信息请阅读该主机上的 **/u2/emacs/GETTING.GNU.SOFTWARE** 文件。

也可以直接向 FSF 订购 GNU 软件，收取象征性费用，覆盖磁带、处理和运费。FSF 接受可抵税的金钱捐赠，也接受软件和硬件捐赠。FSF 还想减少软件之外其他领域对复制的无谓限制——比如，他们正在反对一项禁止复制数字音频信号的提案。

关于 GNU 和 FSF 的更多信息，见 1983 年 10 月的《Byte》，那里首次发表了《GNU 宣言》。这份宣言、许可、担保以及其他哲学文章（如《Some Easily Rebutted Objections to GNU’s Goals》）也收录在每本 GNU 手册里。

## 9.2.5 MINIX

MINIX（Mini-UNIX）是阿姆斯特丹自由大学（Vrije Universiteit）的 Andrew Tanenbaum 编写的一套兼容 V7 的 UNIX。（“Mini”指它相对于伯克利、System V 这类现代 UNIX 系统而言体量很小。）

软件版权归 Tanenbaum 所有；但你可以向 Prentice-Hall 连同一本描述整个系统的书一起买下它，完整源码也很便宜（1988 年 80 美元）。源码不含任何 AT&T 代码，因此完全不受其许可限制。

MINIX 运行在 IBM PC、XT、AT 及兼容机上。它支持硬盘，但只用软盘也能跑（还能读写 MS-DOS 软盘）。与 UNIX V7 一样，MINIX 是多任务的，附带兼容 V7 的 shell、K&R C 编译器、类 emacs 编辑器，以及一大套工具和库。除 C 编译器需另购外，完整源码都在书中。由于价格低廉、能在 PC 上运行、随附完整源码，MINIX 是想深入了解 UNIX 和一般操作系统的人的理想系统。

MINIX 的内部结构与 V7 差别很大，但对普通用户来说，两套系统的功能完全一样。（其实有四个很少用到的 V7 系统调用未在 MINIX 中支持。）这套系统是为教学而设计的，MINIX 教材对其有完整描述。学生可以获准复制软件用于学习和移植到其他 CPU。Usenet 新闻组 comp.os.minix 讨论 MINIX。

MINIX 附带的 C 编译器基于阿姆斯特丹编译器套件（Amsterdam Compiler Kit）。该套件是一个雄心勃勃的项目：让编译器共享大量公共组件，各种语言只需少量独立前端，各机器只需独立后端来生成机器码。

该套件可从 UniPress Software 或 Transmediair Utrecht BV 获得。Tanenbaum 等人的《A Practical Tool Kit for Making Portable Compilers》（《Communications of the ACM》第 26 卷第 9 期，1983 年 9 月）对它作了描述。
