# UNIX 生活：写给每个人的指南

本项目是《UNIX 生活：写给每个人的指南》（*Life With UNIX: A Guide For Everyone*）的简体中文翻译，由 FreeBSD 中文社区译制。

**翻译状态**：全书初译完成（2026 年 10 月），共 129 个页面；结构、引号与 markdownlint 检查均通过。校对进展见 [CHANGELOG.md](CHANGELOG.md)，术语以 [术语表](yi-zhe-shuo-ming.md) 为准。

---

《UNIX 生活》是那本“另一种”UNIX 书。它讲的是手册没讲的、UNIX 入门书没讲的、UNIX 课程没讲的。这本书研究的是字里行间的东西——而学习 UNIX，恰恰就是这种字里行间的功夫。

不过，读《UNIX 生活》可不用你费心去猜字缝里的意思。我们把话全都挑明了：别的书字里行间缺的那些，加上 UNIX 的过去、现在和未来，还有我们能想到的一切。哦，对了，我们还搜罗了不少重要的轶事，以及各种古怪的 UNIX 幽默。

不管别人怎么说，UNIX 都不是从手册里、甚至也不是从源码里就能学会的。UNIX 远不止这些东西。要理解 UNIX，就要理解它的用户、它的应用，也要理解它的失败和缺陷。这些正是本书想讲的一部分。

**它不是一本 C 或 UNIX 编程的教科书**（好书已经够多了）。你不会从中学到怎么写 shell 脚本，也不会知道内核里有什么——好吧，也许知道一点点。但你会学到很多有用的东西，正好填上你已经掌握的、关于 UNIX 的那些有用的和没用的知识之间的缝隙。

这本书想做成一本聚焦于 UNIX 的《Computer Lib》与《全球概览》（Whole Earth Catalog）的结合体。无论你是 UNIX 新手还是老手，都应该能从中有所收获。

**图书信息**

* 书名：Life With UNIX: A Guide For Everyone
* 作者：Don Libes、Sandy Ressler
* 出版：普伦蒂斯-霍尔（Prentice Hall），Englewood Cliffs, New Jersey，1989 年 4 月
* ISBN：0-13-536657-7
* 页数：372 页
* UNIX 是 AT&T 的注册商标

**内容特色**

* 按“过去、现在、未来”“信息”“内部”“外部”四部分组织：从 1969 年的 MULTICS 到 1989 年的 UNIX 战争
* 讲述手册里永远不会写的历史、政治、内幕与笑话
* 用户、程序员、管理员三个视角全面透视 UNIX 环境
* 收录 Usenet、公有领域软件、UNIX 地下世界的种种掌故
* 附有大量 1980 年代 UNIX 书刊、会议、厂商与公司的地址名录

**关于作者**

Don Libes 与 Sandy Ressler 都是 UNIX 的老用户和推广者。Don Libes 后来以 Expect 工具闻名于世，该书署名“Life With UNIX 合著者，其他乏善可陈”，就出自本书作者自己编写的人物志。

本书的编辑与排版全程在一台运行 UNIX 的 Sun Microsystems 工作站上用 Frame Maker 完成，成书胶片由 PostScript 文件经 Linotronic 100P 照排机输出——用作者自己的话说，这在当时本身就是一件值得写进书里的事。
