# 4.5 图书

市面上的 UNIX 和 C 图书多得惊人。该读哪些、该避开哪些，很难判断，因为没人能把它们全读一遍。不过，有一些经典是应该熟悉的。

我们之所以把许多书称作经典，是因为它们常被别人引用，而不一定因为它们更优秀。事实上，有些书不过是某个主题上的第一本，并因此扎下了根。我们既提值得摆上书架的经典，也提应当避开的经典；此外还收录了一些虽非经典、却值得一提的书。每本书都按面向读者、实用性、持久价值和可读性四项，在 1 到 10 分的尺度上评分。

> **译注**：原书用四条灰色刻度条表示评分，这里把刻度条量出的区间取整到个位照录，误差不超过一格。面向读者：1 为新手，10 为巫师；实用性：1 为毫无用处，10 为极其有用；持久价值：1 为转瞬即逝，10 为经典；可读性：1 为晦涩难懂，10 为文笔流畅。

**Advanced Programmer’s Guide to UNIX System V**

* 作者：Rebecca Thomas、Lawrence Rodgers、Jean Yates
* 出版：麦格劳-希尔（McGraw-Hill）
* 评分：面向读者 6–10，实用性 5–10，持久价值 6–9，可读性 5–9

对 System V 用户和程序员来说是一本好参考书。书中有许多出色的 shell 脚本和 C 代码示例，尤其是进程间通信方面。别把它和 Yates 与 Thomas 合著的《User Guide to the UNIX System》搞混了。

**《高级 UNIX 编程》（Advanced UNIX Programming）**

* 作者：Marc J. Rochkind
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 6–10，实用性 5–10，持久价值 6–9，可读性 6–10

这本出色的书系统地讲解了 UNIX 系统调用层面的编程。作者详细介绍了每一个系统调用，并配有示例代码；对信号、进程间通信这类高级主题也有全面论述。本书假定读者只懂一点 UNIX，但所有 UNIX 专家都会想把它放在手边。全书以 System V 及其衍生版本为对象，不过作者也讨论了可移植性问题，并具体提到 BSD、XENIX 等系统。

**《AWK 程序设计语言》（The AWK Programming Language）**

* 作者：Alfred Aho、Brian Kernighan、Peter Weinberger
* 出版：艾迪生-韦斯利（Addison-Wesley）
* 评分：面向读者 3–8，实用性 4–10，持久价值 5–9，可读性 4–9

面对 AWK 原始文档里的种种问题，这本书是期盼已久的答案。它由 AWK 的作者亲笔写成，终于讲清了 AWK 这门被大大低估的语言/工具强在哪里。书中例子丰富，从入门概念一路讲到完整应用，几位作者为这门语言的好用程度立下了大功——从数据库原型、报表生成器到递归下降解析器，都能见到它的身影。

**The Bell System Technical Journal 57, no. 6, pt. 2, July/August 1978**

* 作者：贝尔实验室员工
* 出版：贝尔实验室（AT&T），普伦蒂斯-霍尔（Prentice-Hall）重印
* 评分：面向读者 4–10，实用性 3–5，持久价值 8–10，可读性 7–10

这是 BSTJ 的一期 UNIX 专刊，收录了重要的 UNIX 文章。论文从不同视角描述 UNIX（包括 Thompson 和 Ritchie 的视角），还有若干篇介绍重要 UNIX 应用及相关工作。几乎篇篇都是经典。

**AT&T Bell Laboratories Technical Journal 63, no. 8, pt. 2, October 1984**

* 作者：贝尔实验室员工
* 出版：贝尔实验室（AT&T），普伦蒂斯-霍尔（Prentice-Hall）重印
* 评分：面向读者 6–10，实用性 3–7，持久价值 6–9，可读性 5–9

这本刊名几经变更，是 BSTJ 的另一期 UNIX 专刊。一如既往，文章写得极好，篇篇经典；涵盖了许多新应用和新领域。与早先那期不同，这里有几篇文章对过去做了清晰的回顾。

**《C 语言参考手册》（C: A Reference Manual）**

* 作者：Samuel Harbison、Guy Steele, Jr.
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 1–10，实用性 9–10，持久价值 6–9，可读性 9–10

表面上是一本参考手册，实际远不止于此。它的覆盖面之全，完全可以当 C 语言实现者指南来用。文风简洁，却又不失随和，可以一页页从头读到尾，每页都能学到有用的东西。如果你桌上只放一本 C 书，就该是这本。

**《C 程序设计语言习题解答》（The C Answer Book）**

* 作者：Clovis Tondo、Scott Gimpel
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 6–10，实用性 5–10，持久价值 6–9，可读性 5–9

本书给出了 K&R 一书中全部习题的解答，还用替代技巧重新解决了许多例子。注意此书有两个版本在印，分别对应 K&R 的两版。

**《C 程序设计语言》（The C Programming Language, First Edition）**

* 作者：Brian Kernighan、Dennis Ritchie
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 4–8，实用性 6–10，持久价值 9–10，可读性 6–10

这是第一本出版的 C 教材。书中包含完整的 C 参考手册，写得好到多年来一直充当权威的 C 手册，无论对初学者还是编译器作者都是如此。它已被第二版取代（见下一条），但 C 黑客仍该收一本，用来对付 K&R（即 ANSI 之前的）编译器。人称“K&R”或“白皮书”。

**《C 程序设计语言》（The C Programming Language, Second Edition）**

* 作者：Brian Kernighan、Dennis Ritchie
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 4–8，实用性 6–10，持久价值 9–10，可读性 8–10

这是对原版 K&R 的彻底重写，基于 ANSI X3J11 标准，包含新例子、一个简版 cdecl、关于语言改动的讨论，以及一份与 yacc 兼容的文法。封面依然是白的。学 C 就该用这本书，它注定成为经典。

**《C 语言解惑》（The C Puzzle Book）**

* 作者：Alan Feuer
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 4–10，实用性 3–5，持久价值 5–8，可读性 5–8

字面意义上的一本 C 谜题集，比如推算各种晦涩 C 表达式的值。许多人把这本书说成新晋黑客的磨牙棒，但它关注的东西层次极低。我们不推荐靠读这本书学 C——除非你想让脑袋里塞满一辈子大概只用得上一次的冷门怪知识。自己动手写些读得懂的程序，是健康得多的练习。

**《C++程序设计语言》（The C++ Programming Language）**

* 作者：Bjarne Stroustrup
* 出版：艾迪生-韦斯利（Addison-Wesley）
* 评分：面向读者 6–10，实用性 7–10，持久价值 6–9，可读性 4–6

本书介绍 C 语言的继任者 C++。作者本人就是 C++ 的作者，所以书中的描述和语言之间不可能有任何出入。说实话，这本书勉强算教程，更像参考手册。从很多方面看，它让我们想起 Kernighan 和 Ritchie 那本 C 语言的奠基之作。它无疑会被后来者取代。

**The Design and Implementation of the 4.3BSD UNIX Operating System**

* 作者：Samuel Leffler、Marshall Kirk McKusick、Michael Karels、John Quarterman
* 出版：艾迪生-韦斯利（Addison-Wesley）
* 评分：面向读者 8–10，实用性 4–8，持久价值 7–9，可读性 4–10

本书出色地描述了 UNIX 内核的内部算法和数据结构，内容针对 4.3BSD UNIX。

**《UNIX 操作系统设计》（Design of the UNIX Operating System）**

* 作者：Maurice J. Bach
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 6–10，实用性 4–8，持久价值 7–9，可读性 7–10

本书出色地描述了 UNIX 内核的内部算法和数据结构。内容针对 UNIX System V，但其中大部分对多数现代 UNIX 版本都通用。与 Lions 那本书不同，本书不含任何专有源码，而是给出伪代码或重写的代码。不过，它目前仍是学习 UNIX 内核内部机制最好的书。本书按 UNIX 操作系统一学期课程教材来设计。

**Introduction to Compiler Construction with UNIX**

* 作者：Axel Schreiner、H. George Friedman, Jr.
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 2–10，实用性 9–10，持久价值 7–9，可读性 6–9

这本出色的书专讲如何高效使用 lex 和 yacc。它惜字如金，却详尽说明了 yacc 和 lex 用户面临的问题以及绕开的办法。只要你用这两个工具，就该把这本书放在手边。全书通过构建一个小型 C 编译器来推进。不过，书中许多材料也适用于 lex、yacc 在编译器之外的用途。它讲解析理论及相关领域不多，偏重实用，读者最好对编译原理有基本了解，才能收获最大。

**Life with UNIX: A Guide for Everyone**

* 作者：Don Libes、Sandy Ressler
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 1–10，实用性 4–10，持久价值 7–10，可读性 5–9

全面论述 UNIX 究竟是怎么回事，涵盖技术、市场与历史三个维度。书中包含许多稀有材料和别致的章节，比如 UNIX 人物志、公有领域与地下 UNIX、UNIX 名言集锦，以及一篇对它自己的溢美之评。

**Introducing the UNIX System / Introducing UNIX System V**

* 作者：Rachel Morgan、Henry McGilton
* 出版：麦格劳-希尔（McGraw-Hill）
* 评分：面向读者 1–5，实用性 7–10，持久价值 5–8，可读性 9–10

作为 UNIX 入门教材，我们给予这本书最高推荐。它内容极全面，读起来却轻松。另有专门讲 System V 的版本。

**Nutshell Handbooks**

* 作者：奥莱利（O’Reilly & Associates）员工
* 出版：奥莱利（O’Reilly & Associates）
* 评分：面向读者 1–8，实用性 7–10，持久价值 5–8，可读性 6–10

一套出色的手册，涵盖 Usenet、curses、termcap、vi 和 make 等主题。每本都是关于某一领域的加长版文章，配有大量示例、帮助信息和参考资料。

**《操作系统设计：Xinu 方法》（Operating System Design: The XINU Approach）**

* 作者：Douglas Comer
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 6–10，实用性 5–10，持久价值 8–10，可读性 9–10

这本出色的书讨论 XINU（“XINU Is Not UNIX”）操作系统的实现。虽然 XINU 与任何 UNIX 版本都不兼容（源程序不经修改跑不起来），但 XINU 具备许多 UNIX 特有的特征。书中给出并详细讨论了 XINU 操作系统（在 LSI 11/2 上）的实际代码，包括引导汇编程序。本书适合作为操作系统通识课程的辅助教材，也可以和 Lions 那本书一起用于 UNIX 内核课程。它还提供了一些在 UNIX 环境中实现 C 的洞见。普伦蒂斯-霍尔另售一盘可选磁带，内含书中讨论的 XINU 操作系统。

**Operating System Design: Internetworking with XINU**

* 作者：Douglas Comer
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 4–10，实用性 6–10，持久价值 5–8，可读性 9–10

本书是《The XINU Approach》的姊妹篇。它在 XINU 系统之上构建 TCP/IP 网络，并配上 shell 和一个无状态网络文件系统。与前一本书一样，完整实现尽收书中，文档极其详尽。两本书都强调实用、立即可用的知识；即便时效性渐失，其叙述之清晰也始终能弥补这一点。

**《操作系统：设计及实现》（Operating Systems: Design and Implementation）/ MINIX for the IBM PC, XT and AT**

* 作者：Andrew Tanenbaum
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 1–10，实用性 5–10，持久价值 3–8，可读性 6–9

这些书介绍 MINIX 系统。MINIX 是 V7 UNIX 的公有领域重写版，运行在 IBM PC 及其他几种微处理器系统上。虽说系统内部与原始 V7 UNIX 差别很大，但对于已经绝版的 Lions 那本书，本书是极好的替代品。

**Portable C and UNIX System Programming**

* 作者：J. E. Lapin
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 6–10，实用性 6–10，持久价值 5–8，可读性 7–10

本书旨在指导用户编写可移植的 C 和 UNIX 程序。它对各种 UNIX 版本做了很好的比较，并指出了编写可移植代码时的许多陷阱。

**System V Interface Definition**

* 作者：AT&T
* 出版：AT&T Information Systems
* 评分：面向读者 2–10，实用性 7–10，持久价值 6–8，可读性 4–7

本书描述 AT&T UNIX System V 标准。它只是若干 UNIX 标准之一，却是最早被普遍使用的，因而成了通用的参考。

**《UNIX 操作系统》（The UNIX Operating System）**

* 作者：Kaare Christian
* 出版：约翰威立（Wiley Interscience）
* 评分：面向读者 3–7，实用性 6–8，持久价值 6–8，可读性 8–10

一本全面的 UNIX 系统入门书，可以说是在手册的简略与 K&P 的随和之间取了个折中。书写得不错，但对初学者来说可能过于细致，读起来会有点吃力。

**《UNIX 编程环境》（The UNIX Programming Environment）**

* 作者：Brian Kernighan、Rob Pike
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 1–9，实用性 7–10，持久价值 8–10，可读性 8–10

本书把 UNIX 编程的基本概念串成一体，通篇使用并展开现实世界中的例子，是初学 UNIX 系统程序员的绝佳读物。人们常用作者姓名的首字母称它“K&P”，它看来注定会像其兄弟 K&R 一样成为经典。

**The UNIX System**

* 作者：Stephen R. Bourne
* 出版：艾迪生-韦斯利（Addison-Wesley）
* 评分：面向读者 2–6，实用性 5–9，持久价值 4–7，可读性 4–8

本书是出色的入门书，也能把读者带到中级 UNIX 工具的水平。作者组织了一套极其清晰的示例，说明如何把各种不同的程序耦合成一个连贯的系统。讲数据操作工具的一章尤其有用。

**UNIX Programmer’s Manual / UNIX System Administrator’s Manual / UNIX System User’s Manual**

* 作者：AT&T 员工
* 出版：AT&T、普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 4–10，实用性 1–10，持久价值 1–10，可读性 1–10

这些就是真正的 UNIX 系统手册。它们由多个渠道出版，各家版本略有差异（用户当心）。AT&T 销售 System V 及更早版本的手册，Holt, Rinehart and Winston 则代表 AT&T 出版其中一些手册。

**4.3BSD UNIX Manuals**

* 作者：加州大学伯克利分校
* 出版：Howard Press（由 USENIX 协会代理）
* 评分：面向读者 4–10，实用性 1–10，持久价值 1–10，可读性 1–10

这就是真正的伯克利 UNIX 系统手册。

**UNIX System Administration**

* 作者：David Fiedler、Bruce Hunter
* 出版：Hayden Book Company
* 评分：面向读者 3–7，实用性 7–9，持久价值 6–8，可读性 8–10

一本讲 UNIX 系统管理的出色著作，请把它摆在桌上，和你那套特定系统的管理手册放在一起。

**X/OPEN Portability Guide**

* 作者：X/OPEN 成员
* 出版：普伦蒂斯-霍尔（Prentice-Hall）
* 评分：面向读者 2–10，实用性 7–10，持久价值 3–8，可读性 4–8

本书讲述如何按照 X/OPEN 的要求编写可移植的系统和代码。这套多卷本内容极其全面，但随着 X/OPEN 标准工作的推进，它肯定还会变。
