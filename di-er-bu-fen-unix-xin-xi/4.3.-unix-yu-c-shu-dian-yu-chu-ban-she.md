# 4.3 UNIX 与 C 书店及出版社

下面是我们所知、备有本领域全部或大部分重要书目的书店。我们虽然推荐这些店，但最好先打个电话问问某本书有没有货、什么时候能到。所有书店都提供常备书目清单。（完整地址见附录 A。）

* **Cucumber Bookshop, Inc.**——Cucumber 备有市面上所有 UNIX 和 C 图书，但不卖杂志。可邮购或电话订购，24 小时内处理。接受信用卡和支票。
* **Computer Literacy Bookshop**——全球最大的计算机与电子类书店，备有大部分 UNIX 和 C 书目。接受信用卡和支票，可隔夜送达。
* **Computer Systems Resources, Inc.**——CSRI 销售 UNIX 参考书和教程。邮购接受支票；电话订购货到付款。
* **Jim Joyce’s UNIX Bookstore 与 Uni-Ops Books**——这两家都有相当丰富的 UNIX 和 C 相关图书、期刊、速查卡和海报。

如果你常去的书店缺某本 UNIX 书，别处也找不到，还可以直接打电话向出版社订购。不过出版社的送货时间往往比书店长得多。
