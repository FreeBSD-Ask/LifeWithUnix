# 5.3 课程

> “学一门新编程语言的唯一办法，就是用它写程序。”——Brian Kernighan

大公司往往能养得起自己的教员，或者有能偶尔开课的员工。入门课程用这种方式上很好。如果你所在的组织没那么大，但想上类似课程的人还不少，公司也可以一次性请一位教员上门授课。

这比自己请假去外面听课更好：教员会把课程调整得更贴合你的需求，或者更适合你公司的需要。当然，市面也有大量交钱就能上的课程和讲座。1987 年，典型的三天或四天课程，每名学生收费 1,000 美元。

大多数厂商都为自己的软硬件用户开课。不过，某些 UNIX 主题太通用了（比如 C shell 编程），即便你没有那家的设备，也大可考虑去听。个别主题可能要求学生出示 UNIX 源码许可。

下面列出的公司都在全国各地开班，方便你就近上课，也提供上门授课。有几家还提供录像带和视盘课程。录像带在便利性上登峰造极，唯一的缺点是没法向教员提问；而视盘课程往往是交互式的，可以定期考你，也可以让你在感兴趣的章节之间来回跳跃。

以下是一些规模最大的课程供应商：

* AT&T：不出所料，AT&T 教 UNIX 课程的历史比谁都长，课程种类（今年超过 40 门）和选项也最丰富。AT&T 还真的颁发 CEU（继续教育学分）。许多课程有录像带版本。
* Computer Technology Group：CTG 提供大量 UNIX 和 C 主题的课程，除美国外还在加拿大和英国开课，有视盘课程。
* Digital Equipment Corporation：DEC 提供 ULTRIX 内部机制和 C 编程课程。
* Institute for Advanced Professional Studies：IAPS 提供许多 UNIX 主题的课程，尤其在高级领域有专长。
* Lurnix：Lurnix 提供多种 UNIX 主题以及 C 编程课程，还有一套基于《UNIX for People》一书的自学方案。（见讲印刷资料的章节。）
* Uni-Ops：Uni-Ops 提供多种课程，如 UNIX 系统安全、面向程序员的 386 UNIX，甚至有“高级 vi”。
* USPDI：美国职业发展学院（U.S. Professional Development Institute）是非营利组织，提供可获 CEU 学分的 UNIX 和 C 课程，由 DPMA 教育基金会赞助。
* Integrated Computer Systems：ICS 在美国和加拿大提供 C 与 UNIX 课程，同样内容的课程也有视频版。
