# 5.4 用户组

> “我拒绝加入任何愿意接纳我当会员的俱乐部。”——Groucho Marx

UNIX 用户组有若干全国性和国际性的组织。如果你靠 UNIX 谋生，加入其中一个是值得的；你的公司也可能想成为企业会员或赞助方。

用户组最出名的是它们每年或每半年一次的会议，但它们提供的服务远不止于此：支持标准化工作、扶持地方用户组、传播信息、资助有益于会员的项目。大多数用户组都是非营利组织。

**国际用户组**

国际性的 UNIX 用户组有 /usr/group、USENIX 和 EUUG。

/usr/group 是面向商业用户和其他最终用户的国际组织。它每年出版《UNIX Products Directory》，双月刊 CommUNIXations，半月刊 /usr/digest，并主办年度 UniForum 会议。/usr/group 是解读商业 UNIX 用户与营销者所关心问题的一流信息来源。它在制定 UNIX 标准方面一直在做大量工作，包括赞助许多工作组、出版大量标准解读文件，还资助全国性和地方性用户组。

USENIX 是面向技术和学术 UNIX 用户的国际组织。它出版双月刊 ;login:，以及季刊《Computing Systems》——一本评审制的 UNIX 相关论文期刊。USENIX 每年还主办多个会议和研讨班，许多 UNIX 奠基性论文最先在那里发表。一般来说，UNIX 开发者和研究者的用户组首选就是 USENIX。该组织资助实验性项目（如 UUNET、Stargate），并提供会员捐赠源码的软件交换。Usenet 新闻组 comp.org.usenix 上讨论 USENIX 相关事务。

/usr/group 和 USENIX 的历史见历史那一章，它们的出版物和会议在本章别处和讲印刷资料的章节里有进一步介绍。

EUUG（European UNIX User Group，欧洲 UNIX 用户组）也是国际性用户组。但与 /usr/group 和 USENIX 不同，EUUG 从不掩饰自己的偏向：它的会议、出版物和其他活动都以服务欧洲用户为宗旨。（讽刺的是，EUUG 会议的官方语言却是英语。）EUUG 会议每年两次；出版月刊 EUUGN；许多欧洲国家用户组的成员会自动获得 EUUG 会员资格。

**各国用户组**

许多国家都有 UNIX 用户组——有些国家还不止一个。USENIX 和 /usr/group 虽是国际组织，但它们的直接活动（如会议）历来主要在北美。澳大利亚 UNIX 用户组、法国 UNIX 用户协会（Association Francaise des Utilisateurs d’UNIX）这类国家用户组，则致力于在本国推广 UNIX。这些用户组定期聚会、出通讯、办各种服务，与国际用户组的工作互为补充。其他知名的国家用户组还有日本 UNIX 协会（Japanese UNIX Society）、韩国 UNIX 用户组、荷兰国家 UNIX 用户组、新西兰 UNIX 系统用户组和 /usr/group/UK Ltd.。这些用户组的地址见附录 A。

**NZUSUGI**

NZUSUGI 即新西兰 UNIX 系统用户组，每年举办一次会议，有人说这是少数仍然值得参加的 UNIX 会议之一。会议相当随意，参会人数也就几百——还不算羊（会上总有讲不完的羊的笑话）。

**地方用户组**

大多数国家和国际用户组都有地方分支。比如，全世界较大的城市大多有用户组；许多较小的国家也有国家用户组。查找本地用户组最省事的办法，是联系前面列出的那些大用户组：他们会告诉你，本地区有没有他们知道或资助的用户组。

这些地方性 UNIX 用户组是结识本地 UNIX 人才、交流 UNIX 和 C 技巧与心得的好去处。多数小组有定期聚会和通讯，会上通常鼓励交换公有领域软件，你还能听到关于 UNIX 新产品或新项目的报告。

有些用户组还开课，虽然偏随意，但便宜得多，质量大概也不比商业课程差多少（见本章别处）。

除这些之外，还有大量“个人/业余计算机爱好者团体”也能为你牵线 UNIX 同好。它们并非专为 UNIX 或某种软硬件服务，但人多到足以支撑兴趣小组：其中通常都有 UNIX 兴趣小组，而且必定有 C 兴趣小组。（别忘了，C 在 PC 和其他微处理器系统上可是极受欢迎的语言。）

如果你想自己组建 UNIX 用户组，可以联系前面列出的某家大用户组。它们对符合自身利益的地方用户组很有兴趣，会帮你起步：通常替你寄出第一轮邮件、提供本地区会员名单、在自家刊物上提到你，还可能为新组提供启动经费。

**厂商用户组**

许多用户组专属于某家厂商或某个产品，其中最活跃的有 ADUS（Apollo DOMAIN Users’ Society）、DECUS UNIX SIG（DEC 用户组 UNIX 特别兴趣小组）和 SUG（Sun 用户组）。它们都有围绕自家系统的通讯和会议，还有装着用户投稿软件的分发磁带。

许多厂商专属用户组由厂商自己出钱支持。因此，这类会议的展区里不会有竞争对手的展台——换句话说，在会议展区里货比三家，一般只能限于不与主办厂商竞争的产品。当然，如果你要找的正是那些不与主办厂商竞争、但能在其产品上运行或与之配合的产品，这类会议倒是个绝佳的市场。

与大多数用户组不同，厂商用户组一般是营利组织。

**其他一些团体**

你完全可以把生命的每一天都花在参加不同的 UNIX 用户组会议和研讨班上，一场非 UNIX 活动都不去（更别说干活了）。现实中，ACM、IEEE 这类专业组织里还有许多未必面向 UNIX 的会议和特别兴趣小组。这不意味着它们无视 UNIX；相反，它们也许能提供更平衡的视角。

这本书哪怕你只读了一小部分，也会发现我们的许多资料来源并不在 UNIX 圈内。不因为一样东西不是 UNIX 就视而不见，对你只有好处。UNIX 固然是个美妙的系统，可它也毫不客气地从其他操作系统和环境里借走了许多想法。对其他系统了解得和 UNIX 一样多，你就多一分优势。也只有到那时，你才真正懂得了 UNIX 的世界。

在这里列举那些无关但值得关注的用户组并不合适，不过确实有两个与 UNIX 间接相关的用户组值得一提：Software Tools 用户组和 C 用户组。

Software Tools 用户组（STUG）的历史与重要性在历史那一章有详细讨论。STUG 至今活跃，尽管它的许多工作已由 UNIX 实现取代。

STUG 继续提供虚拟操作系统（VOS）软件的分发磁带，覆盖大量不同的计算机系统，磁带里还有用户投稿的软件。STUG 的会议与 USENIX 的例会同步举行，每半年一次。

C 用户组（CUG）顾名思义专攻 C 语言。它每年出版八期《C Users Journal》——一本对 C 程序员极好的杂志。不过，CUG 最初出名靠的是分发会员投稿的软件。这些软件面向多种操作系统（包括 UNIX），大多用 C 写成。（当然，也有一小部分用汇编；另外有些 C 程序是其他语言的编译器和解释器。）

CUG 自称拥有“世界上最大的公有领域 C 软件收藏”，分发手段也相当专业：能写多种介质格式（包括 tar 和 cpio），你要的话还能隔夜发运。1988 年，每卷收费 8 美元，目录里共有 135 卷（5¼ 英寸软盘）。
