# 1.4 1979 年：第 7 版

1979 年，UNIX 第 7 版发布。V7 配备了完整的 K&R C 编译器，并首次引入强制类型转换、联合体和 typedef。它还提供了一个更精巧的 shell（名为“sh”，又叫“Bourne shell”，取自其作者之一 Stephen Bourne 的名字）。系统支持更大的文件；移植工作的成果也体现出来：内核更健壮，为许多外设配上了新的设备驱动程序。

第 7 版的程序员手册膨胀到约 400 页（一卷仍然装得下，还绰绰有余）。《UNIX Readings》成为第二、第三卷，每卷各约 400 页。

John Reiser 和 Tom London 在贝尔实验室把 V7 UNIX 移植到了一台 VAX 上，这次移植被称作 UNIX 32V。某种程度上，VAX 很像一台放大版的 PDP-11，按这个思路处理，移植工作就相对轻松。这也是一个典型例子：机器有明显的硬件能力（分页）却被搁在一边，只求尽快把 UNIX 跑起来。尽管如此，这个不支持分页的 UNIX 版本在实验室内部仍被广泛、长期使用，因为它的地址空间（4 GB）比 PDP-11 大得多。这个版本也给到了伯克利，成为后者进一步研究工作的基础。

Whitesmith 是第一家商业 C 编译器厂商。不巧的是，当时许可的边界还不清晰，于是他们的 C 编译器库故意采用了不兼容的子程序与参数约定。后来人们判定，C 的用户接口（如子程序名）并不受版权保护。Whitesmith 的 C 如今已与 UNIX 兼容。
