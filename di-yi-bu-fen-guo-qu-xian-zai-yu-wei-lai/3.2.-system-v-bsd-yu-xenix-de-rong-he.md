# 3.2 System V、BSD 与 XENIX 的融合

无论 UNIX 的定义是否被标准化，总会有一些产品成为事实标准。这种情况在 UNIX 界频繁发生，因为 UNIX 开发者只有少数几家，却把 UNIX 转售给大量 VAR。

最大的开发者显然是 AT&T，它做的一切都可能影响 UNIX 的未来。（其实处于这一位置的开发者还有几家，包括 IBM、Sun、微软，以及 Berkeley 这类主要研究机构。）

![System V、BSD 与 XENIX 的融合趋势：现在（左）与未来（右）](../.gitbook/assets/fig-3-2-merging.png)

> **译注**：原图为“System V、BSD 与 XENIX 的融合趋势”示意图。左侧的“现在”是 BSD、XENIX、V7、System V 四个相互交叠的圆，其中 V7 居中；右侧的“未来”里，BSD 与 XENIX 化作两个同心圆环，把 System V 套在正中，内圈标着 POSIX、X/OPEN、SVID 与“???”，意指各标准逐渐收拢到 System V 周围。

AT&T 显然正努力把 XENIX 和 BSD 的重要特性并入 System V。它和主要的 XENIX、BSD 厂商达成了协议，要推出统一的 UNIX 版本。我们认为这番努力会成功：其他厂商（见[走进现实世界](../di-si-bu-fen-unix-zhi-wai/12.-unix-zou-jin-xian-shi-shi-jie.md)一章）早已这么做过，而且大受欢迎。一旦 AT&T 拿出统一的 UNIX 版本，它无疑会比任何其他 UNIX 更普及。
