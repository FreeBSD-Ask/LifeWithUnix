# 2.7 可移植性 第二幕

可移植性的第二个方面，是 UNIX 本身就可移植。这意味着它能在形形色色的机器上运行：从微机（IBM PC 及兼容机）到小型机（PDP-11、Interdata），从超级小型机（VAX、68000）到大型机（Amdahl、IBM），再到超级计算机（Cray）。它还被移植到了采用新奇架构的机器上（RISC），甚至能与其他操作系统同机共处（VM、VMS）。

这之所以可能，部分原因是 UNIX 本身用高级语言 C 写成，而 C 也移植到了这些机器上；其他操作系统大多用汇编或自家的专有高级语言编写。其次，UNIX 对底层的硬件假定很少，索取也很少。这固然意味着在同样的硬件上可以做出比 UNIX 更快的系统，但也意味着你拿到的是一个在其他许多机器上被反复折腾了数百人年、可靠性高得多的操作系统，而且你的老应用全都能继续跑。这正是 UNIX 构成诱人市场基础的原因之一——它实现过的硬件种类，比所有其他操作系统加起来还多。

除了能在许多计算机上运行，UNIX 还支持大量不同的外设。通过 termcap 或 terminfo，它能支持无穷多种终端——这两套系统用高层描述语言来刻画终端的能力。（见程序员环境一章里讲终端处理的部分。）
