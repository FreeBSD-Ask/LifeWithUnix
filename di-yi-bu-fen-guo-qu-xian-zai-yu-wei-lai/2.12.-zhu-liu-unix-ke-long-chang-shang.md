# 2.12 主流 UNIX 克隆厂商

UNIX 兼容产品（以下就简称“克隆”）市场早在 AT&T 售出第一份 UNIX 副本之前就存在了（见历史那一章）。当初催生克隆的许多理由（比如 UNIX 缺乏支持）如今已经消失，但有些还在。例如：

* **克隆不需要 AT&T 许可。** 克隆厂商不必遵守 AT&T 的定价和许可限制。

虽然 UNIX 再许可的价格已经便宜到足以与其他操作系统竞争，但对某些公司来说仍是一笔不必要的开销。还有一些古怪的许可做法让人很不方便：比如许可费用取决于任意时刻的用户数；又比如 AT&T 的源码不得再分发，而许多别的公司以源码形式分发代码，从而免去为不同机型生成二进制的麻烦。

* **克隆可以做非标准的增强。**

AT&T 为符合 System VR3 制定了极其严格的规矩：比如厂商不得做某些非标准增强。对于 UNIX 未覆盖的计算领域（如实时处理），这给了厂商一个难题——要么放弃这块市场，要么不能宣称自己的产品是 UNIX。

好在其他 UNIX 标准或许能提供产品分类的办法，让买家仍能明智地拿 UNIX 与类 UNIX 产品作比较，并多少知道关键差异在哪里。

我们已多次强调，UNIX 既是一个授权的操作系统，也是一种哲学。许多公司借此做起了生意，提供 UNIX 克隆、兼容品、相似品、仿制品等等。这些 UNIX 兼容产品很好地服务了很大一部分市场。其中一些厂商是：Charles River Data Systems（UNOS）、Concept Omega 公司（Thoroughbred O/S）、Cromemco 公司（Cromix）、Flexible Computing 公司（MMOS）、Mark Williams 公司（Coherent）、Quantum Software Systems（QNX）和 Whitesmiths 公司（Idris）。
