# 2.8 UNIX 许可

计算机领域最令人头大的问题之一，是围绕软件、硬件和固件的所有权与权利的那堆法律问题。许多领域至今没有定论。涉及 UNIX 时，谨慎为上。AT&T 早已圈好了自家的地：UNIX 及其概念、软件和名称，都被它用专利、版权和商标保护了起来。而为一桩 AT&T 的官司掏律师费，多半能让大多数公司破产。虽然 AT&T 从未把哪家公司告上法庭，但它的律师们好几次登门，善意地“建议”你调整行为。

AT&T 的 UNIX 许可费相当混乱，因机器、操作系统版本和用户数而异，再加上第三方厂商和开发者，更是乱上加乱。

UNIX 许可基本上分两种：源码许可和二进制许可。源码许可买的是在一台机器上阅读源码、修改、重新编译并运行的权利；其余一切都要另外加钱（见下文）。一份源码许可包含针对一种机器架构的全套 UNIX 源码，而 AT&T 提供的架构只有很少几种。二进制许可买的是在一台机器上运行 UNIX 的权利（含某些重配置权），就这么多。

最简单的许可是按机器计费：你可以在一个 CPU 上运行 UNIX；想在另一个 CPU 上跑一模一样的 UNIX，就得再掏钱。实际上，额外收费取决于不少因素：

* 最便宜的是单用户系统，多用户许可更贵，还分好几档。（不，没有任何机制阻止你超出许可用户数——守不守合同，全凭自觉。）

* 你拿到的源码只针对一种 CPU；想要另一种，加钱。

* 你拿到的源码只对应一个版本；想要另一个，加钱。

* 你不许把源码或二进制分发给任何人。想分发二进制（其中包含 AT&T 的专有代码，比如库），必须购买分发许可（加钱）；想分发源码，同样要加钱，而且卖方必须向 AT&T 购买或持有与源码对应版本的 UNIX 许可。

/usr/group 有一篇讲 UNIX 许可的出色文章。

AT&T 的客户通信中心（Customer Communication Center）也会试着向你解释 UNIX 许可。当然，既然这套东西就是 AT&T 自己以一种最令人费解的方式搞出来的，你也别指望它是最容易读懂的来源。

好在大多数人用不着深究许可的这些琐碎。如果你是为自用而买一套 UNIX 系统，卖方通常已经把 UNIX 许可费打包进系统价格里了。
