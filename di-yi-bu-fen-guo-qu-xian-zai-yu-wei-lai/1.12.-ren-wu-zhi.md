# 1.12 人物志

我们没法列出所有为 UNIX 出过力的人，只能列出一些常被提及的名字——哪怕只是在 UNIX 会议上的闲聊里被提及。

追查某些 UNIX 开发参与者并不容易。许多人没留下可辨认的署名，尽管他们的贡献相当可观；还有些人整体贡献很大，却很难归到某个具体的部分（看起来有好几百人都在内核上捣鼓过）。总之，若有遗漏，敬请见谅。

不少 UNIX 相关人士，是靠别的、不相干的项目出名的（有时甚至更出名）。这些与 UNIX 无关的贡献我们一概不列——倒不是我们目光短浅，而是光写这些就够写一整本书了。

有些人有广为人知的外号，通常是因为它们出现在早期版本随附的 **/etc/passwd** 里，或者因为他们的首字母遍布源码。我们把外号也一并列出，这样当你听人说“dmr 说过……”，就知道指的是 Dennis Ritchie。

* Mike Accetta：符号链接、key（后来的 `man -k`）以及 **/dev/pty** 的负责人。
* Rick Adams：UUNET 背后的主要推手，写了 SLIP。
* Alfred Aho：awk 里的 A，egrep 与 dbm 库的作者。
* Eric Allman：写了 sendmail、trek、tset 和 -me 宏，Ingres 的重要贡献者。
* Ken Arnold：写了 curses、fortune，还有一大堆别的游戏。
* Özalp Babaoglu：与 Bill Joy 共同负责伯克利 UNIX 的虚拟内存。
* W. O. Baker：驳回了 Thompson、Ritchie 和 Ossanna 要 DEC-10 的请求；于是才有了一台小得多的机器，和一个规模小得多的操作系统。
* Andreas Bechtolsheim：完成了 SUN 板的初始设计。
* Steve Bellovin：写了 Usenet 的第一个实现。
* Walt Bilofsky：写了 Rand 编辑器。
* Biff：Heidi 的狗。
* Irma Biren：第六版 UNIX 的磁带都是她寄出去的。
* Bruce Borden：参与了 MH 和 Rand 编辑器。
* Steve（“srb”）Bourne：创造了 Bourne Shell，写了 adb。
* Steve Bunch：与别人合写了 UNIX 上第一份 Arpanet（NCP）代码。
* Brent Byer：加入指令/数据空间分离，以支持 PDP-11/45。
* Ron Cain：写了 Small C，第一个公有领域 C 编译器。
* Rudd Canaday：与 Dennis、Ken 共同设计了 UNIX 文件系统，创建了 PWB 小组。
* Lorinda Cherry：Writer’s Workbench（diction、style 等）、bc 和 dc 的作者；与 bwk 合写了 eqn。
* Greg Chesson：前 Woody Herman 乐队鼓手；mpx 文件（select() 的前身）、初代 uucp 包驱动、Datakit、线路规程以及 dh 驱动中自适应控制的开发者。
* Douglas Comer：写了 Xinu；与 Paul McNabb 完成第一个 UNIX X.25 实现，与 Bob Brown、Keith Williamson 完成 System V 的 cron。
* Dave Crocker：写了 MMDF、MS。
* Bill Croft：写了第一个 UNIX 网际互联实现（用 PDP-11）。
* Ted Dolotta：-mm 宏的负责人，USG 的第一任主管。
* Robert Elz：写了 BSD 的配额与自动配置。
* Robert Fabry：伯克利 CSRG 的早期指导教师，为项目争取到了 DARPA 经费。
* Stu（“sif”）Feldman：make、f77 和 efl 的作者，有一座很棒的酒窖。
* Mel Ferentz：主办了第一次 UNIX 用户组会议，创办 UNIX News（即后来的 ;login:）。
* David Fiedler：创办或主编过的 UNIX 和 C 杂志、通讯比谁都多，包括 The UNIX Software List、The C List、Unique、UNIX Review、The C Journal 和 The C Users Journal。
* John Foderero：写了 Franz Lisp。
* Herb Gellis：写了 xargs。
* Jim Gettys：X Window System 的共同负责人。
* George Goble：完成了第一次有影响力的 UNIX 移植——把 UNIX 移植到由两台 VAX-11/780 组成的非对称多处理机上。
* James Gosling：写了 UNIX emacs；与 David Rosenthal 合著了 NeWS。
* Gary Grossman：与别人合写了 UNIX 上第一份 Arpanet（NCP）代码。
* Rob Gurwitz：写了 BBN 的 TCP/IP 实现，后来并入了伯克利的发行版。
* Doug Gwyn：写了 BRL 为 BSD 做的 System V 模拟层。
* Teus Hagen：建立了美国（decvax）、欧洲（mcvax）与其他许多国家之间最早的 uucp 连接。
* Dick Haight：写了 find、cpio、expr；给 shell 加了具名变量；PWB 的重要贡献者。
* Chuck Haley：写了 tar；与 Bill Joy 共同实现了早期版本的 ex 和 Pascal shell。
* Dennis Hall：在劳伦斯伯克利实验室共同实现了第一个虚拟操作系统；创办了 Software Tools 用户组。
* Robert Henry：写了 error。

* Mark Horton：写了 curses、terminfo，在 uucp 映射项目和 Usenet 上做了大量工作。

* Bill（“wnj”）Joy：写了伯克利初版发行中的大部分内容，包括虚拟内存支持、网络、Pascal、vi、csh 和 termcap；Sun Microsystems 的联合创始人；设计了 NFS；因伯克利 UNIX 方面的工作获得 1986 年 ACM Grace Murray Hopper 奖。

* Howard Katseff：写了 sdb 和 last。
* Lou Katz：USENIX 的第一任主席。
* Brian（“bwk”）Kernighan：K&R 里的 K，也是 awk 里的 k；合著了《C程序设计语言》（The C Programming Language），为大多数人写 C 的风格定了调；写了 ratfor、ditroff、eqn 和 pic；对第 7 版负共同责任。
* Andrew Koenig：写了 varargs（也就是 stdargs）。

* Bob Kridle：创办了 Mt. Xinu。

* Peter Langston：负责早年 USENIX 围棋赛。他的朋友 Eedie 和 Eddie，通常打 (201) 644-2332 就能找到。
* Sam Leffler：与 Bill Shannon 合写了 tip；4.2BSD 和伯克利 TCP 的主要推手。

* Don Libes：《UNIX 生活》的合著者，其他乏善可陈。
* John Lions：写了第一本介绍并记录 UNIX 系统的书。名字常被错拼成“Lyons”。
* Tom London：32V（UNIX 的第一个 VAX 版本）的共同负责人。
