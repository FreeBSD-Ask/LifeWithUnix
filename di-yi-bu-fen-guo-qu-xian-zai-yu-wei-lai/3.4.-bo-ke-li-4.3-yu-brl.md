# 3.4 伯克利 4.3 与 BRL

伯克利的 UNIX 研究仍在继续，只是速度比从前慢了许多。4.3 BSD（Berkeley Software Distribution）发布后，许多促成伯克利工作的干将已经倦了——多年拿着学生的薪水干活，除了在 UNIX 会议上被人认出来，几乎没什么好处。不少人创办了公司卖 UNIX 产品，一些人跳槽去了渴求 UNIX、薪水优渥的大公司，还有几个干脆回学校念书毕了业。

伯克利还会继续发布新的 BSD 版本，只是节奏比过去慢；与此同时，许多公司走上前来接过了缰绳。其中一个有意思的动向是：当年出资扶持伯克利 4BSD 研究的国防部，决定资助陆军的弹道研究实验室（BRL），让它来维护 BSD UNIX。维护和支持从来都是伯克利不提供的，而 BRL 恰恰以向伯克利各版本提交了大量 bug 修复而闻名。BRL 还把伯克利 4.2 的代码配上 System V 兼容包重新发布，也发布了 4.3 BSD 的一个版本并持续在其上工作。
