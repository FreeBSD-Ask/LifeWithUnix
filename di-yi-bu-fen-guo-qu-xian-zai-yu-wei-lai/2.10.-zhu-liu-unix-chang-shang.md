# 2.10 主流 UNIX 厂商

UNIX 是 AT&T 的授权产品，因此正牌 UNIX 的每个版本都是从 AT&T 获得许可、基于某个 AT&T 版本的。不过，这既不意味着 AT&T 拿下了大部分销量，也不意味着它拿走了大部分利润。

事实上，1987 年初 Microsoft 声称，全世界 300,000 份 UNIX 许可中有三分之二是 XENIX——即 Microsoft 的 UNIX 版本。当然，其中大多数是相对便宜的二进制许可，价格在 1 到 500 美元之间。转售商买进一台哪怕只要 5,000 美元的 UNIX 机器，每卖出一份二进制 UNIX 就得向 AT&T 付 100 美元——到头来，大头还是转售商赚走的。转售商多半已经买下了完整的 UNIX 源码（1986 年约 45,000 美元），这是一次性支出，得摊到每台售出系统的收入里去。

尽管如此，许多计算机公司还是选择购买 UNIX 源码许可，成为 UNIX VAR（增值转销商）。假设一家公司以每台 10,000 美元卖出 500 套整机，毛收入就是 5,000,000 美元；从中扣掉 60,000 美元的源码许可费和每套 100 美元、共 500 套的二进制费，还净剩 4,890,000 美元，可供在花哨包装和一点增值开发上挥霍。这个例子里，按系统摊算、直接归因于许可的成本只有 220 美元，占最终零售价的 2%。

前面说过，在卖给最终用户的许可数量上，Microsoft 和 SCO 领先。不过它们过去瞄准的是低端单用户系统，而其他多数公司选择覆盖高端单用户或多用户系统。ABC 公司可能在 PC 上跑着 XENIX，500 个 UNIX 用户人手一份 XENIX；XYZ 公司则可能 500 个用户共用五台 Cray。显然，UNIX 的许可数或售出份数，并不总是用户数的可靠指标。每当看到有人拿 UNIX 许可数和 MS-DOS 许可数作比较，我们就会想起这一点：MS-DOS 数以百万计，可每一份都限于单用户系统。（高端多用户 XENIX 系统和多用户 MS-DOS 兼容系统是有的，但只占市场的一小部分。）

在再许可协议的数量上，Microsoft 和 SCO 是领跑者；但按实际用户数算，AT&T 才是第一。非正式调查显示，按用户数没有哪家过半，不过 AT&T 系的 UNIX（主要是 System III 和 System V）约占市场的 35%。所以 AT&T 宣称 System V 是“标准的 UNIX”，更准确的说法应该是“最流行的标准 UNIX”。

System V UNIX 在许多机器上都有。与 XENIX 的移植版不同，纯粹的 System V 移植覆盖了从微机到超级计算机的全谱系。不过 XENIX 和 System V 正慢慢变成一回事：许多程序在 XENIX 和 System V 主机之间移植时只需微小改动、甚至不用改，这个比例还在不断增大。AT&T 和 Microsoft 为某些机器定了二进制标准——使用相同硬件的两类系统上，程序无需重新编译即可运行。

有成百上千家公司在销售基于 XENIX 和 System V 的系统，比较知名的包括 Apple（A/UX）、Arete Systems 公司（Arix）、Databoard 公司（D-NIX V）、Hewlett-Packard 公司（HPUX）、IBM 公司（IX 和 AIX）。X/OPEN 的努力在欧洲最受关注，而日本的 MITI（通商产业省）也明确表达了愿望：想要基于 System V 加伯克利扩展的开发环境。

把 XENIX 和 AT&T 的市场份额相加，约占 44%，剩下的主要是伯克利各变种、克隆品，以及某些专门化的 UNIX 版本。

伯克利是所有伯克利版 UNIX 的源头。自 1977 年以来，它已分发了数千份 1BSD 和 2BSD（面向 PDP-11）以及 4BSD（面向 VAX），在可预见的将来还会继续。伯克利的 UNIX 事业为学校拉来了研究经费、好学生和好教员，也提升了计算机系的声望。即便在伯克利之外，它的 UNIX 也主导着整个 UNIX 市场的研究与走向——因为新想法往往最先在那里冒出来。

你可以直接从伯克利获取 UNIX，但那是研究产品，不是商业产品，支持得另找地方。此外，伯克利不提供（甚至不推荐）硬件，硬件也要你自己搞定。许多公司看准这片空白，提供软件支持（如 Mt. Xinu）或完整的商业系统（如 Sun、DEC、Wollongong，都基于伯克利 UNIX）。其中值得一提的是 Mt. Xinu：既然伯克利不为自己分发的软件提供支持，几位离开伯克利的人便成立了 Mt. Xinu 当作支持小组——收集 bug 与补丁并重新分发，此外还销售自家的伯克利 UNIX 版本（more/BSD）。与伯克利不同，Mt. Xinu 能为你把 UNIX 配置到大到一大票设备与计算机上，省去了身边非得有位 UNIX 大师的麻烦。

卖伯克利移植版的公司比卖 System V、XENIX 移植版的少，但它们过得相当不错。比如 Sun Microsystems 就是工作站总销量冠军，这恰好说明以伯克利为基础的厂商瞄准的是什么市场：它们更偏向科学、工程和学术应用，而这一市场对伯克利 UNIX 的接受度很高。这类用户约占 UNIX 用户群的 20%。

销售伯克利系 UNIX 的公司包括：Convex Computer 公司、Digital Equipment 公司（Ultrix）、National Semiconductor（Genix）和 Sony Microsystems。支持伯克利 UNIX 的厂商较少，并不奇怪：伯克利对支持和未来走向的态度，不是谁都招架得住；而且伯克利交付的系统要变成商业产品，需要做大量修改。BSD 绝对不是玩具，但也不是拆开即用的包装食品。执着的程序员似乎并不介意——伯克利 UNIX 确实更合许多程序员的心意，它在研究机构里枝繁叶茂也是顺理成章。可对公司而言，要把它打磨成商业成品，活儿就多得多了。

和 XENIX 一样，市场上要求把伯克利 UNIX 与 System V 合并的压力很大。但与 XENIX 不同的是，伯克利 UNIX（至少在伯克利）将保持鲜明的独特——永远是一个探索新想法的研究项目，其做法必然与现有系统不兼容。不过，伯克利 UNIX 的商业实现已经磨掉了它最初的莽撞。我们看到，伯克利 UNIX 正在慢慢地和 System V 融合（就像 XENIX 一样）。

当然，有人觉得这融合的速度堪比板块漂移。于是许多厂商干脆同时提供多个版本，号称“双宇宙系统”（dual universe，Pyramid 发明的说法）——不少厂商巧妙地拿出了能同时运行伯克利和 System V 程序的系统。这类厂商有：Apollo Computer 公司（DOMAIN/IX）、Pyramid、Sequent Computer Systems 公司（Dynix）、Sequoia Systems 公司（TOPIX）、Sun Microsystems（SunOS）和 Wollongong 集团（Eunice SV/BSD）。

光谱的另一端，是一些出于种种原因有意牺牲与 AT&T 或伯克利 UNIX 兼容性的厂商。比如大多数商业 UNIX 版本不支持实时计算——过去这意味着此类产品的厂商必须对 UNIX 系统做重大修改，而许多厂商干脆无视这些扩展带来的兼容问题。考虑到当时仅有的标准又老又弱、充其量只是既成事实，这种做法可以理解。
