# 2.11 主流 UNIX 硬件商与移植商

如果手头的硬件比较常见，你可以从一众移植商手里买到 UNIX。比如 1987 年 1 月，要搞到 PC/AT 上的 UNIX，可选的有 Mark Williams（Coherent）、Interactive Systems（IN/ix）、Microport Systems 公司（System V/AT）、微软（XENIX 第 5.0 版）、Opus Systems（Opus5）、普伦蒂斯-霍尔公司（Minix）、Quantum Software Systems 公司（QNX）、Santa Cruz Operation 公司（SCO XENIX System V）、VenturCom 公司（Venix System V）和 Whitesmiths 公司（IDRIS）。

此外，还有许多公司把这些系统稍作改动就在 PC 上转售。例如 IBM 就同时卖 SCO 的 XENIX、微软的 XENIX 和 Interactive 的 IN/ix。

PC 是基于 Intel CPU 芯片的计算机。这些芯片在价格和 CPU 性能之间取得了很好的平衡；在采用更强劲芯片（如 Intel 80386）的 PC 上，UNIX 那种直截了当的多处理架构能轻松得到支持。这类芯片组普遍受到 UNIX 厂商的青睐。

它们的特点是相对便宜、速度快，对多处理操作系统架构有良好支持，能寻址至少 2³² 字节的虚拟内存，物理内存至少能支持 4 MB。下表列出了一些基于常见芯片组销售 UNIX 或 UNIX 系统的厂商。

这张表是 1987 年初 UNIX 供应商的一次快照，并不完整，只是用来说明：有大量厂商在种类极少的几种芯片组上提供 UNIX 系统。同时请注意，选择 AT&T 或 XENIX、而非伯克利 UNIX 的厂商为数众多。

UNIX 已在几乎所有类型的计算机系统上实现过，全部列出毫无意义。对任何一种硬件来说，要么硬件制造商自己提供 UNIX（有时明明已有自家的专有操作系统），要么第三方厂商能提供。

一家公司同时卖 UNIX 和专有操作系统，看起来奇怪，但两者未必互相竞争：有些操作系统的专长领域并不是 UNIX 覆盖的。不过，同时支持两套操作系统成本高昂，所以大多数公司都避而不做。而那些从专有操作系统起家的公司，最终无一例外都把支持扩展到了 UNIX——需求大得让人无法无视，不管为此要付出多少重复资源的代价。

在自己的硬件上同时提供专有操作系统和 UNIX 的公司有 DEC、IBM、HP、DG、Apollo、阿姆达尔、微软、英特尔、摩托罗拉、Gould、Unisys、NCR、IBM、Data General 和克雷等，另外还有几百家。

许多以 UNIX 系统起家的新公司则不必操心支持专有系统这回事。但另一方面，它们得操心竞争：既然大家用的是同一种操作系统，不满意的用户拍拍屁股就能把代码搬到另一台跑 UNIX 的系统上。因此，UNIX 厂商必须对用户更上心。

有些公司只提供基于 UNIX 的系统：Sun、Silicon Graphics、Wollongong、Unity、LPC、Venix、Multiflow、CAE/SAR、Convergent Technologies、MIPS、Pyramid、Ridge、MAD Intelligent Systems 和 Fortune。这些公司各有各的优势：有的覆盖低端市场，价格非常有竞争力；有的提供不寻常的特性，比如实时支持，或同时支持多个版本（Berkeley 与 System V）。

前面我们观察到，使用常见低端 UNIX 芯片组的大多数公司都采用 System V 或 XENIX 实现。这个规律在专有机型上就不成立了。原因之一是：早期的 System V 和 XENIX 不支持这些硬件系统的要求，而伯克利版支持——或者稍加改动就能支持。比如，伯克利支持虚拟内存比其他商业 UNIX 系统早了好几年，而这对需要大内存系统的应用（如大型机或超级小型机）是绝对必要的。

上表的最后一行，是生产通用移植（即移植到多种架构）的公司。Berkeley 勉强算一个——它不是商业公司，但它是唯一持续把伯克利 UNIX 移植到许多不同架构上的。右侧那四家公司包办了表中位于它们上方的大部分实现，以及许多未能列出的实现。

Unisoft 做的移植最多，估计占全部移植的 65%。Unisoft 把自己的移植版叫“Uniplus+”，不过它一直紧密基于最新的 AT&T 版本，我们干脆把它和 AT&T 版本视为同一回事。

SCO 做了许多移植，包括把 XENIX 移植到 8086。SCO 与微软就 XENIX 的开发签有联合协议，SCO 是 XENIX 的官方第二来源。

如果你需要把 UNIX 移植到一块新硬件上，可以直接与 SCO、Unisoft、微软、Interactive、AT&T 或其他移植公司签约。把 UNIX 移植到“说得过去”的硬件上，花费大约 100,000 美元，耗时三到六个月。相比之下，其他大多数操作系统的移植要贵上十倍，开发时间也长得多。

这些公司全都只提供 System V 移植，但都“带伯克利增强”，例如 C shell、作业控制和虚拟内存管理。比如 AT&T 现在把 vi 编辑器（来自伯克利）作为 System V 的官方编辑器予以支持。可惜，“带伯克利增强”这句话没有严格定义，所以你应该问清楚它到底指什么。
