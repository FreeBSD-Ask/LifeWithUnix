# 3.7 C++

C++ 是一门基于 C 的语言，但它绝对是一门新语言。这个名字是拿 C 的自增运算符（++）开的玩笑——把一个变量加上 ++，它就大一号。所以 C++ 听起来像是 C 的下一个版本。

C 其实是门老语言了。从它诞生那天起，就有许多人试图改进它；但 K&R 把 C 描述得太过精确，让大部分建议都碰了壁，C 的演化因此十分有限，迈出的步子都很小。这些演化见 Larry Rosler 的《The Evolution of C – Past and Future》（《AT&T Bell Laboratories Technical Journal》第 63 卷第 8 期，1984 年 10 月）。ANSI C 标准是 C 走向成熟的下一个台阶。

C++ 试图在保留 C 全部好想法的同时，再添上许多新东西。事实上，C++ 与 C 向上兼容——所有 C 程序在 C++ 里都能编译（好吧，几乎所有）。出于保持兼容的考虑，C 的一些毛病被留了下来，但也有许多得到了修正。

C++ 确实是一门比 C 更优越的语言。它最引人注目的特性包括更好的类型检查、更好的数据抽象设施、运算符重载，以及对面向对象编程的内建支持。结果是一门比 C 好用得多的语言：C++ 保留了 C 的大部分风味，仍可用于系统实现，但代码更容易组织，更不容易写出有 bug 的代码，子程序更容易复用，成品代码也更有可能更高效。

C++ 的各种实现，典型做法是写成 C 编译器的预处理器，不过其定义为本身并不要求这一点。C++ 可从多家厂商获得（见讲应用的章节）。想了解更多，可以读 Bjarne Stroustrup 的《The C++ Programming Language》——他在贝尔实验室工作时设计了这门语言。

虽然 C++ 的实现从 1983 年起就有了，我们估计还得过些时候，多数 C 程序员才会转向它。不过我们希望，终有一天大多数 C 程序员会把它当作自己的语言来接受。（Ada、Modula-2 之类也是选择，但我们认为 C++ 夺得 C 现有程序员和应用群体的机会大得多。）
