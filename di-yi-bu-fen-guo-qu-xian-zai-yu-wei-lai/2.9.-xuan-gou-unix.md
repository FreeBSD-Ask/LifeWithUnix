# 2.9 选购 UNIX

## 2.9.1 做出决定

买 UNIX 系统就该像买任何计算机系统一样：头脑清醒，保持冷静，经验能帮上大忙。如果你没有经验，就去认识有系统的人；更好的办法是找到那些用着和你相同应用的人，跟他们聊聊。

别被功能迷了眼，尤其别被销售人员的视角牵着走。那些基准测试数据，除非明确是用相似硬件的系统、跑着你的应用测出来的，否则一概无视。尽量以应用为导向：这套系统能做到你想要的吗？现在就有现成的应用能做到吗？它能满足你未来的需求吗？

这套系统与你已有或正在使用的其他系统兼容吗？在把自己的程序和数据都移植过去之前，别信 UNIX 可移植这回事。要意识到：所有 UNIX 系统并不都一样——硬件的差异通常一目了然，软件的差异通常看不出来。

有一台自己的计算机来学习是件美事，但 UNIX 系统很贵，而且你可能会发现，UNIX 系统对你的需求来说纯属杀鸡用牛刀。如果你只图玩游戏，UNIX 机器多半不适合你。对自己诚实一点：你到底为什么需要一台计算机？

看看能不能借别人的 UNIX 系统用上一段时间。UNIX 是多用户系统，只要你不跑大程序，把情况解释清楚，很多管理员都通情达理——你还得保证只在晚上用。

去本地大学报一门计算机课程，整个学期你都能用上 UNIX 机器。

## 2.9.2 具体操作

买 UNIX 有若干途径。与大多数程序不同，买 UNIX 格外复杂，原因就是前面讲过的 AT&T 许可要求。

AT&T 持有 UNIX 最初的商标和版权，售出的每一份副本都直接或间接地经它许可。AT&T 提供好几个 UNIX 版本（比如 V7、System III、System V）。每份许可都写明适用于哪台或哪类机器（按 CPU 划定）、最多多少用户、是二进制许可还是源码许可，还要看买方的类型（政府、商业、学术），以及你是否打算转售 UNIX 或把它嵌入产品。

如果你买的是预先配置好的 UNIX 版本，多半不会直接和 AT&T 打交道。比如 XENIX 就是 Microsoft 销售的 UNIX 授权版本，你可以直接向他们买，按 PC 单用户操作预配置，附带最基本的源码。

UNIX 厂商还会把工具和应用拆开卖，你可以只买比如 C 开发工具。拆分销售的好处通常是价格低于整套系统，但正因如此，你得格外仔细地确认所购系统包含你需要的软件部件。比如，如果你以后打算添加设备驱动程序，多半得另付钱购买那些能重建 UNIX 的程序。

如果你买的是 UNIX 仿制品，就不用向 AT&T 支付许可费，这类软件理应便宜些。不过也未必：许多 UNIX 克隆厂商声称自家产品完全重写，值任何真操作系统的价钱。对他们更有利的一点是，许可规则宽松得多——比如有些 UNIX 仿制系统随附完整源码，对你拿它做什么几乎不加限制。

除非你直接从 AT&T 购买 UNIX 系统，否则你就是你所购厂商的客户。有问题、有疑问，找那家公司，别找 AT&T；必要时由那家公司去联系 AT&T。
